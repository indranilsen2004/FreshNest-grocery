FreshNust Grocery

A modern grocery website designed to help users explore fresh and organic products with a clean, simple, and user friendly interface. This project focuses on delivering a smooth browsing experience while promoting healthy and eco conscious shopping choices.

Overview

FreshNest Grocery is a front end web application that connects users with fresh produce and organic products. It is built with simplicity and performance in mind, making it easy for users to navigate, explore categories, and discover products effortlessly.

Features

- Clean and responsive user interface
- Fresh and organic product showcase
- Category based browsing
- Customer review section
- Blog section for tips and updates
- Smooth navigation and structured layout

Tech Stack

- HTML
- CSS
- JavaScript

Project Structure

- index.html for main layout
- style.css for design and styling
- script.js for interactivity
- images folder for assets

How to Run Locally

1. Download or clone the repository
2. Open the project folder
3. Run the index.html file in your browser
